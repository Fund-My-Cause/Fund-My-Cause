feat(#677): add webhook system for campaign events

- Create apps/interface/src/lib/webhooks/webhook.service.ts
  - WebhookSubscription: id, url, events[], secret, ownerId, active, createdAt
  - WebhookDelivery: id, webhookId, event, payload, status, attempts,
    lastAttemptAt, nextRetryAt, responseCode, error, createdAt
  - registerWebhook(): HTTPS-only URL validation, generates random 32-byte secret
  - updateWebhook() / deleteWebhook(): ownership-gated
  - rotateSecret(): generates new signing secret for a webhook
  - listWebhooks(): masks secret (shows first 8 chars + ...)
  - signPayload(): HMAC-SHA256(secret, `${timestamp}.${body}`) for signed delivery
  - verifySignature(): timing-safe comparison with timestamp tolerance (5 min)
  - dispatchEvent(): fan-out to all matching active subscriptions
  - attemptDelivery(): POST with x-fmc-signature + x-fmc-timestamp headers,
    10s timeout, 5 attempts with exponential backoff (0s, 30s, 5m, 30m, 2h),
    moves to dead status after MAX_ATTEMPTS, schedules retries via setTimeout
  - getDeliveryLog(): delivery log newest-first with limit
  - getDeadLetterQueue(): filter by status=dead
- Create apps/interface/src/app/api/webhooks/route.ts
  - GET /api/webhooks — list owner's webhooks (x-wallet-address auth)
  - POST /api/webhooks — register new webhook, returns subscription with secret
- Create apps/interface/src/app/api/webhooks/[id]/route.ts
  - GET /api/webhooks/:id/log?limit= — delivery log
  - GET /api/webhooks/:id/dlq — dead-letter queue
  - PATCH /api/webhooks/:id — update url/events/active
  - PATCH /api/webhooks/:id/rotate — rotate signing secret
  - DELETE /api/webhooks/:id — delete subscription

Closes #677
